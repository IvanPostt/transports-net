# 🚀 Django Проект - Шаблон Веб-Приложения

## Описание проекта
Привет! Это такой себе стартовый набор для создания своего первого веб-приложения на Django. Думай об этом как о готовом шаблоне: здесь уже есть самые основные штуки, которые нужны почти в любом проекте. Мы собрали тут базовые части, чтобы ты мог сразу начать делать что-то крутое, не тратя время на скучную настройку с нуля.

Django - это как очень умный помощник для программистов на Python. Он делает большую часть рутинной работы за тебя, так что ты можешь сосредоточиться на том, чтобы твоё приложение делало что-то уникальное и интересное. В этом проекте ты увидишь, как работают основные фишки Django: как хранить данные (модели), как показывать их пользователям (представления и шаблоны), и как правильно настроить ссылки на разные страницы (URL-маршрутизация).

## 🎯 Возможности
Здесь ты найдешь несколько готовых "приложений" (так в Django называются отдельные части проекта), которые уже умеют делать полезные вещи:
*   **Пользователи (`users`):** Это приложение умеет всё, что связано с юзерами. То есть, люди могут регистрироваться, входить на сайт, менять свои данные в профиле. А ещё есть штуки для подтверждения почты и сброса забытого пароля - очень удобно!
*   **Магазин (`shop`):** Это мини-интернет-магазин. Сейчас тут можно посмотреть список "товаров" (мы их называем "транспортами", но это неважно), посмотреть подробности о каждом, положить в корзину и увидеть, что ты выбрал.
*   **Работа с данными:** Все данные (ну, например, про пользователей или про товары) хранятся в базе данных. Django помогает очень легко с ними работать через специальные "модели". Тебе не нужно писать сложный SQL-код, Django сам всё сделает!
*   **Красивые страницы:** В проекте есть готовые странички (HTML-шаблоны) для разных разделов: главная, товары, корзина, вход, регистрация, профиль. Всё это динамическое, то есть меняется в зависимости от того, что делает пользователь.
*   **Админка:** У Django есть своя супер-удобная админ-панель. Это как панель управления для твоего сайта, где ты можешь легко добавлять, удалять или редактировать пользователей и товары, не заходя в код.

## ⚙️ Клонирование проекта
Чтобы начать работать с этим проектом, тебе нужно получить его копию. Это делается очень просто:

1.  **"Клонируем" проект (загружаем на свой комп):**
    Открой свой терминал (командную строку) и введи вот эту команду. Она скопирует все файлы проекта на твой компьютер:
    ```bash
    git clone https://github.com/IvanPostt/transports-net
    ```
    После этого у тебя появится папка `transports-net` со всем кодом.
## 🚀 Запуск проекта
Окей, проект у нас на компе. Теперь давай его запустим, чтобы он заработал! Делай всё по порядку:

1.  **Создаём "чистое" окружение (это важно!):**
    Представь, что у каждого проекта свои инструменты. Чтобы они не мешали другим проектам, мы создаём "виртуальное окружение". Это как отдельная коробочка для наших инструментов. Открой терминал в папке проекта (`transports-net`) и введи:
    ```bash
    python -m venv venv
    ```
    Потом эту коробочку нужно "открыть" (активировать):
    *   **Если у тебя Windows:**
        ```bash
        .\venv\Scripts\activate
        ```
    *   **Если у тебя macOS/Linux:**
        ```bash
        source venv/bin/activate
        ```
    Ты поймёшь, что всё получилось, когда перед командной строкой появится `(venv)`.

2.  **Устанавливаем все нужные штуки (зависимости):**
    У нашего проекта есть список "ингредиентов" (библиотек), без которых он не будет работать. Они перечислены в файле `requirements.txt`. Установим их все сразу:
    ```bash
    pip install -r requirements.txt
    ```

3.  **Готовим базу данных:**
    Нашему приложению нужна база данных, чтобы хранить, например, пользователей и товары. Django умеет сам её создавать и настраивать. Просто скажи ему:
    ```bash
    python manage.py migrate
    ```

4.  **Создаём "главного" пользователя (администратора):**
    Чтобы заходить в админ-панель (помнишь, где можно всем управлять?), нужен специальный пользователь - суперпользователь. Создадим его:
    ```bash
    python manage.py createsuperuser
    ```
    Терминал попросит тебя ввести имя пользователя, почту и пароль. Вводи и запоминай!

5.  **Запускаем сайт!**
    Ну вот и всё! Последний шаг - запустить локальный сервер, чтобы твой сайт открывался в браузере:
    ```bash
    python manage.py runserver
    ```
    Если всё прошло хорошо, ты увидишь сообщение, что сервер запущен. Обычно он доступен по адресу: [http://127.0.0.1:8000/](http://127.0.0.1:8000/)

## 📖 Использование
Когда ты запустил проект (как описано выше), ты можешь открыть его в браузере и посмотреть, что получилось:
*   **На главную:** Просто зайди по адресу [http://127.0.0.1:8000/](http://127.0.0.1:8000/). Или можешь добавить `/admin`, чтобы попасть в админ-панель (тут пригодятся логин и пароль суперпользователя, который ты создавал).
*   **Изучай:** Смотри разные странички! Все ссылки ты можешь найти в файлах `urls.py` в приложениях (`users`, `shop`) и в основном проекте (`rool`).

## 💻 Технологии
Из чего сделан этот проект? Вот основные "строительные блоки":
*   **Мозг (Backend):** Мы используем Python и Django. Это как связка "двигатель + рама" для нашего веб-приложения. Django делает много работы за нас, чтобы мы могли сосредоточиться на функциях.
*   **Хранилище данных (База Данных):** Все наши данные (пользователи, товары) хранятся в SQLite. Это простая база данных, которая отлично подходит для небольших проектов и обучения, потому что она хранится прямо в файле, и её легко настроить.
*   **Что видит пользователь (Frontend):** Для создания того, что ты видишь в браузере, мы используем HTML (структура), CSS (стили, чтобы было красиво) и немного JavaScript (чтобы странички были интерактивными). Если захочешь, потом можно добавить что-то более продвинутое, например, React или Vue.
