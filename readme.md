# 🚀 Django Проект - Разработка сайта по покупкам транспротных средств

## Описание проекта
Этот проект представляет собой API на Django для работы с товарами, такими как велосипеды, самокаты, квадроциклы и другие транспортные средства. Проект использует Django ORM для взаимодействия с базой данных PostgreSQL и предоставляет базовые операции (CRUD) для управления пользователями и товарами.

API позволяет:

создавать и управлять пользователями (регистрация, вход, изменение данных, сброс пароля);

просматривать, добавлять, редактировать и удалять товары;

работать с корзиной и отслеживать выбранные товары.

Все данные хранятся в базе данных и обрабатываются через Django-модели, что упрощает работу с данными без прямого написания SQL-запросов. Для управления проектом предусмотрена встроенная админ-панель Django, где можно удобно управлять пользователями и товарами через веб-интерфейс.

## ⚙️ Клонирование проекта
Чтобы начать работать с этим проектом, тебе нужно получить его копию. Это делается очень просто:

1.  **"Клонируем" проект (загружаем на свой комп):**
    Открой свой терминал (командную строку) и введи вот эту команду. Она скопирует все файлы проекта на твой компьютер:
    ```bash
    git clone https://github.com/IvanPostt/transports-net
    ```
    После этого у тебя появится папка `transports-net` со всем кодом.
## 🚀 Запуск проекта
Теперь давай его запустим, чтобы он заработал! Делай всё по порядку:

1.  **Создаём "чистое" окружение (это важно!):**
    Представь, что у каждого проекта свои инструменты. Чтобы они не мешали другим проектам, мы создаём "виртуальное окружение". Это как отдельная коробочка для наших инструментов. Открой терминал в папке проекта (`transports-net`) и введи:
    ```bash
    python -m venv venv
    ```
    Потом эту коробочку нужно "открыть" (активировать):
    *   **Если у тебя Windows:**
        ```bash
        .\venv\Scripts\activate
        ```
    *   **Если у тебя macOS/Linux:**
        ```bash
        source venv/bin/activate
        ```
    Ты поймёшь, что всё получилось, когда перед командной строкой появится `(venv)`.

2.  **Устанавливаем все нужные штуки (зависимости):**
    У нашего проекта есть список библиотек, без которых он не будет работать. Они перечислены в файле `requirements.txt`. Установи его такой командой:
    ```bash
    pip install -r requirements.txt
    ```

3.  **Готовим базу данных:**
    Нашему приложению нужна база данных, чтобы хранить, например, пользователей и товары. Django умеет сам её создавать и настраивать.
    ```bash
    python manage.py migrate
    ```

4.  **Создаём "главного" пользователя (администратора):**
    Чтобы заходить в админ-панель, нужен специальный пользователь - суперпользователь. Создай его с помощью команды:
    ```bash
    python manage.py createsuperuser
    ```
    Терминал попросит тебя ввести имя пользователя, почту и пароль. Вводи и запоминай!

5.  **Запускаем сайт!**
    Ну вот и всё! Последний шаг - запустить локальный сервер, чтобы сайт открывался в браузере пропиши такую команду:
    ```bash
    python manage.py runserver
    ```
    Если всё прошло хорошо, ты увидишь сообщение, что сервер запущен. Обычно он доступен по адресу: [http://127.0.0.1:8000/](http://127.0.0.1:8000/)

## 📖 Использование
Когда ты запустил проект, ты можешь открыть его в браузере и посмотреть, что получилось:
*   **На главную:** Просто зайди по адресу [http://127.0.0.1:8000/](http://127.0.0.1:8000/). Или можешь добавить `/admin`, чтобы попасть в админ-панель (тут пригодятся логин и пароль суперпользователя, который ты создавал).
*   **Изучай:** Смотри разные странички! Все ссылки ты можешь найти в файлах `urls.py` в приложениях (`users`, `shop`) и в основном проекте (`rool`).

## 💻 Технологии
Из чего сделан этот проект?:
*   **Backend:** Мы используем Python и Django. Это как связка для нашего веб-приложения. Django делает много работы за нас, чтобы мы могли сосредоточиться на функциях.
*   **База Данных:** Все наши данные (пользователи, товары) хранятся в SQLite. Это простая база данных, которая отлично подходит для небольших проектов и обучения, потому что она хранится прямо в файле, и её легко настроить.
*   **Frontend:** Для создания того, что ты видишь в браузере, я использовал HTML (структура), CSS (стили, чтобы было красиво) и немного JavaScript (чтобы странички были интерактивными).
